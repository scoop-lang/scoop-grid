# 聚合面板与总计原生回归

本 Cone 使用生产 DataGrid、列面板、快速筛选及总计控件。通过真实 AppKit 无障碍动作选择聚合、操作查询，验证全筛选集总计、排序／分页复用、编辑失败与等待保存、动态文案、算术错误、空结果、清除聚合和关闭弹层。它只在本机 macOS 窗口运行一个 Application。

```sh
scoop check --tests --release tests-cones/aggregation
scoop test --release tests-cones/aggregation
```

普通数值、缺值、缓存及失败原子性在主 Cone 的 `GridAggregationTest` 中验证。原生回归沿现有公开无障碍测试接口操作实际控件，没有替代模型动作或模拟焦点完成。


逻辑总计用例通过同一个生产 dataGrid 验证 24 个阶段：全筛选集数值、只读／粘贴拒绝、真实焦点、业务勾选排除、原生选择拒绝、位置／文案更新保留节点、固定行／分页、非法草稿门控、数据替换、范围／查找、隐藏退休／重新显示、禁用、空值／计数、删除度量列及关闭。显式业务行高／跨度回调只接受真实记录。运行两个 Application 测试时分别按完整用例名过滤，保持串行。

总计行显式声明不可选择，原生断言同时检查行仍启用、selected／setter 能力不存在，以及业务选中两条时系统列表也只有两条。最终 24 阶段用例约 1.10 秒通过，随后 39 阶段业务选择回归约 1.19 秒通过；报告完整退出且 failures 为空。
