# 固定行原生回归

使用生产 DataGrid，检查 Top／Body／Bottom 共用的真实行列、滚动和原生 Table。覆盖一亿行惰性来源、固定顺序和身份、分页外固定行、排序／筛选／删除、固定／显式／内容行高、Discarded 阅读位置、三段内容测宽、零正文和固定区裁剪。

原生 Realize／Reveal 和按 key 聚焦共享单元格；编辑器组合输入、校验失败、异步保存、显式固定操作与应用直接移动使用同一编辑合同。另检查 RTL／密度、禁用恢复、空结果与带焦点卸载，记录读取量和唯一挂载实例。

本机 release 的 51 个检查阶段已通过，进程正常退出，failures 为空。关闭后全部实例释放；一亿行测试累计创建少于 4000 格、读取少于 8000 行，不用巨大数据排序代替虚拟化验收。

每次独立运行一个 Application，需要已解锁的 macOS 桌面。原始报告放在仓库外；本地 AppKit 协议检查不代替 VoiceOver 验收。
