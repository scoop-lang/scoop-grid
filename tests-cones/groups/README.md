# 分组表头原生回归

本 Cone 在本机 macOS 使用生产 `dataGrid` 与列工具，验证多级表头、同一组的三个冻结片段、浅层叶表头与正文起点。通过真实 AppKit 指针拖动检查组内重排、跨组拒绝、隐藏成员随整组移动及嵌套组移动，核对原生节点身份与列状态。

原生关系检查读取 ColumnHeaderUIElements：叶表头关联外层／内层组，正文格再关联对应的叶表头；同时核对 group columnSpan 和浅层叶 rowSpan。隐藏后不返回已退休组，根关闭后保留的原生引用不再暴露旧关系。这些检查不代替 VoiceOver 或跨进程客户端验收。

组合覆盖内容测宽、整组隐藏后的表头层数变化、禁用、Escape、RTL／密度、横向虚拟化、组定义替换、原生面板操作、非法编辑／异步保存门控，以及拖动中卸载。每个进程只运行一个 Application；需要已解锁的本机桌面。原始测试报告留在仓库外。

本机 macOS aarch64 的 73 个检查阶段已通过，进程正常退出且 failures 为空。宽组在横向滚动中间取得真实焦点后保持原滚动位置；完整语义 Frame 与可命中裁剪区域分别断言。
