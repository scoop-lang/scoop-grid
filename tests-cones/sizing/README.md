# 可见内容测宽原生回归

本 Cone 使用生产 `dataGrid` 与列面板，在本机 macOS 窗口验证显式内容测宽。主要检查一亿行来源只测当前呈现行，超宽 overscan 行不会参与，部分可见行会参与；横向离屏列只为这些行准备真实控件，自然测量与正常布局保持同一单元格实例。

用例同时覆盖明确样本、空结果、宽度上下限、冻结增长上限、RTL／密度、取消及外部替换、字体集合版本改变、同步／异步编辑提交、受控组合输入、面板原生操作与卸载。每个测试进程只运行一个 Application，要求桌面解锁且测试窗口能取得焦点。

`tests/data/Roboto-Regular.ttf` 与许可证复制自相邻 Scoop 的 `scoop.graphics.text/tests/data`，用于真实登记字体并验证等待请求取消。该 35 KB 测试字体遵循附带的 Apache 2.0 许可证，不作为 Grid 的默认字体。字体作为 Cone 内的编译资源嵌入，运行测试无需外部字体文件或网络。
