# 行内跨列的原生组合

直接使用生产 DataGrid、真实内容 View 和 AppKit 单元格代理。场景从一亿行、30 列开始，只为当前窗口及明确动作准备行列；原生元数据查询不挂载 View。一个测试进程运行一个 Application。

53 个阶段覆盖跨列锚点、横向部分可见、方向键／Tab／Home／End、离屏 Realize／Reveal／Focus、规则替换与节点退休、只读编辑与单格粘贴拒绝、原值 CSV、隐藏／重排／冻结、顶部／底部固定行、RTL／密度和窄窗口。远端显露使用第 5000 万行。

内容行高按合并宽度测量且去重贡献格，内容测宽跳过跨列内容；外部规则变化取消已有编辑及等待中的提交。多级表头关系去重，零宽锚点仍能定位，删除／同 key 重建和根关闭释放旧实例。断言关闭后实例归零、累计构造少于 5000 格、读取少于 30000 行。

先准备当前本机工具链，再运行 `scoop check --tests --release .` 和 `scoop test --release .`。桌面需已解锁且窗口可取得系统焦点；直接使用 AppKit 公开协议的检查不代替 VoiceOver 操作。
