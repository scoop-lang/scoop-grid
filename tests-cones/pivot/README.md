```sh
scoop fmt tests-cones/pivot
scoop check --tests --release tests-cones/pivot
scoop test --release tests-cones/pivot
```

本 Cone 在本机 macOS 串行运行一个 Application；按 Accepted 帧核对实际模型、原生节点和焦点，动作返回值不单独作为通过证据。

本批 release 验收共 45 个阶段，约 1.73 秒完成，failures 为空、end／complete 齐全，进程正常退出。非法草稿保持原值时，原生 Checkbox 按既有合同返回拒绝，后续帧仍须确认编辑错误、原查询和真实焦点。
