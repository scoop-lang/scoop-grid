# 可变行高原生回归

使用生产 `dataGrid` 和一亿行惰性来源，检查固定、显式和指定列内容高度。真实 AppKit Frame 覆盖不同高度、部分可见行、隐藏贡献列、RTL、密度及零高度视口；默认文字与自定义 View 共用行高路径。

数据替换和改序按稳定 key 保持阅读位置；在场景中改变窗口尺寸触发 Discarded，确认旧滚动位置仍保留，下一次 Accepted 才发布修正。横向离屏贡献列、远端按 key 聚焦、原生 Realize／Reveal、编辑器与错误提示撑高、内容测宽及 PageDown 使用同一组真实单元格。

测试记录来源读取量和实际挂载身份，重复挂载立即失败，关闭后要求全部释放。每次只运行一个 Application，需要已解锁的本机桌面；不把本地 AppKit 协议检查写成 VoiceOver 或真实硬件验证。原始报告放在仓库外。

2026-11-20 本机 macOS aarch64 的格式化、check、release 构建及 42 个原生阶段通过，进程 exit 0、failures 为空，运行约 1.17 秒。新增的恢复启用检查覆盖冻结区、中心区及离屏元数据；累计创建少于 3000 格、读取少于 1500 行，关闭后所有实例释放。
