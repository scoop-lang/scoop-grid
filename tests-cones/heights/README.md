# 可变行高原生回归

使用生产 `dataGrid` 和一亿行惰性来源，检查固定、显式和指定列内容高度。真实 AppKit Frame 覆盖不同高度、部分可见行、隐藏贡献列、RTL、密度及零高度视口；默认文字与自定义 View 共用行高路径。

数据替换和改序按稳定 key 保持阅读位置；在场景中改变窗口尺寸触发 Discarded，确认旧滚动位置仍保留，下一次 Accepted 才发布修正。横向离屏贡献列、远端按 key 聚焦、原生 Realize／Reveal、编辑器高度、内容测宽及 PageDown 使用同一组真实单元格。错误 Portal 不改变行高；真实输入框保持 enabled，原生 AXHelp 中错误只出现一次。

测试记录来源读取量和实际挂载身份，重复挂载立即失败，关闭后要求全部释放。每次只运行一个 Application，实际输入和焦点阶段需要已解锁的本机桌面；只读元数据和几何断言本身不依赖系统焦点。不把本地 AppKit 协议检查写成 VoiceOver 或真实硬件验证。原始报告放在仓库外。
