# 单矩形与原生复制回归

使用生产 DataGrid 和本机 AppKit 窗口，验证一个范围与双轴虚拟化、固定行列、真实键盘／鼠标、剪贴板、内部按钮和单格编辑的组合。测试保存并恢复系统剪贴板原有的全部项目与数据格式；要求桌面已解锁且窗口能获得焦点。

```sh
scoop check --tests --release tests-cones/range
scoop test --release tests-cones/range
```

一亿行、80 列的离屏范围只读取复制所需数据，原生离屏格报告选择且不因此挂载。窗口阶段覆盖 Shift 导航与点击、系统菜单 Copy、空字段和表头、RTL、宽度／显隐／排序／分页、不可变值更新、按钮输入归属、编辑器自身文本复制、非法草稿与异步保存、跨列真实值、格式化失败保持原剪贴板、模型替换、禁用和卸载。

原生元数据及 Frame 在 UI owner 回调之外读取，鼠标坐标取自真实单元格；不枚举整张虚拟表格。模型动作只用于明确验证公开应用入口，键盘／点击与鼠标拖动使用实际原生事件。按键同时提供匹配的硬件码、AppKit 字符和修饰键，功能键不附带可打印文字。原生事件入队后，等待下一次 owner 调度与 Accepted 帧再读取结果，避免提前检查旧剪贴板或焦点；复制同时检查回调次数与成功结果。

拖选回归同时覆盖两轴拖动、Shift 延展、跨冻结行列、按钮优先、横纵边缘滚动、来源格离屏后的输入保留、RTL、Escape、外部范围／数据更新、禁用、失焦和卸载。原生 FrameProbe 在释放后做两次定时观察，确认不再请求或呈现动画帧。Touch／Pen 使用 Window 生产队列中的受控触点载荷，验证默认滚动、显式选择模式、第二触点及取消；这不是触摸硬件测试。

查找阶段组合真实 `gridFind` 输入和按钮、Enter、前后循环、横纵离屏定位、未命中保留范围、非法编辑门控、扫描期间数据变更、格式化失败、受控组合输入时禁用提交，以及禁用／卸载后失效。查找动作保持原查询对象；仅实际命中后请求目标格，不为扫描建立 View。
