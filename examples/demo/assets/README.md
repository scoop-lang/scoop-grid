# 演示资源

`icon.png`、`covers/0.png` 至 `covers/9.png`、`avatars/0.png` 至 `avatars/11.png` 均由本例的 `tools/generate_assets.py` 绘制，与本仓库采用相同许可证。PNG 是交付资源，运行和打包无需 Python 或 Pillow。维护时可以安装 Pillow，运行生成脚本重新绘制。

场景和列布局参考 [AG Grid 官方示例](https://www.ag-grid.com/example/)与 [ag-grid-demos](https://github.com/ag-grid/ag-grid-demos)。Inventory 使用其公开示例中的虚构专辑名称作为场景参照，封面为重新绘制的原创抽象图形；头像也为本地绘制。金融报价、员工组织与库存数量都是演示数据，不表示实时市场数据或真实员工资料。项目没有包含 AG Grid JavaScript 库、Enterprise 实现或其图片资源。
