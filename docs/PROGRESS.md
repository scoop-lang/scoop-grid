`examples/basic` 使用同一个生产 `dataGrid` 展示十万行、40 列、Start／End 冻结与表头排序。没有另起演示渲染器。

当前验证：主 Cone 的格式化、check 与 17 项 release 测试全部通过；`tests-cones/window` 的格式化、check 与单个原生复合测试通过，依次覆盖 32 个窗口阶段，其中一亿行宽表阶段累计构造少于 1600 个单元格、读取少于 300 个 Row。原生横向滚轮回归确认了 160 像素位移；导航阶段验证两按钮单元格的内部 Tab 和返回浏览，首尾跨出网格再返回、翻页和 RTL，Enter 没有意外激活按钮。关闭后没有残留挂载。这是惰性呈现与交互验证，不代表一亿行查询／排序性能。示例已通过 check 与 release 构建，并实际检查了中文显示、纵向滚动、固定表头与升降序排序。UI 自动化工具的横向注入未改变窗口，以原生滚轮回归记录该输入路径的结果，不把工具调用本身当成通过。尚未将输入法和离屏 AX 列动作计为通过。

工具链副本位于 `../scoop-work/grid/toolchain`，编译器基于 `e9a3d7fa72`，UI 及其依赖链已同步到包含 PR #158 的 `c808941f4a`；普通 runtime 沿用同代产物。使用共享本地缓存 `../scoop-work/grid/cache`，无需重建未变化的编译器与原生依赖。

上游 [PR #156](https://github.com/scoop-lang/scoop/pull/156) 已合并：精确条目 FocusHandle 选择，24 个原生焦点场景在当前工具链复测通过。[PR #157](https://github.com/scoop-lang/scoop/pull/157) 提供本轮测量输入与公共列宽／extent 算法，A→B→A 测量、嵌套 Lazy、失效访问和 10 项组件几何测试通过。[PR #158](https://github.com/scoop-lang/scoop/pull/158) 提供真实祖先视口绑定，原生焦点、取消、兄弟视口拒绝和卸载测试通过。三项均已独立提交、推送、合并，并更新 main、工作分支及工具链。
