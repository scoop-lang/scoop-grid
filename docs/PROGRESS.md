`examples/basic` 使用同一个生产 `dataGrid` 展示十万行、40 列、Start／End 冻结、表头排序，以及名称／金额的校验与不可变数据提交。没有另起演示渲染器。

当前验证：主 Cone 的格式化、check 与 20 项 release 测试全部通过；`tests-cones/window` 的格式化、check 与单个原生复合测试通过，依次覆盖 94 个窗口阶段，其中一亿行宽表阶段累计构造少于 1600 个单元格、读取少于 300 个 Row。原生横向滚轮回归确认了 160 像素位移。导航验证内部 Tab、首尾跨出、翻页和 RTL；编辑验证解析／校验拒绝、不变值不提交、异步等待／失败／重试、外部其他字段保留、原字段冲突、隐藏列、替换列、删行、滚动、禁用及卸载。双击、点击其他格、无效草稿阻止表头排序、失焦保存／拒绝、旧 completion 在重试后仍失效、提交后被筛选移出及同列后继定位也已通过。迟到完成不能重新打开编辑器。真实系统拼音通过 CGEvent 键盘路径运行，检查原生组合文档、Escape 取消、空格选词和 Enter 提交，并恢复原输入源；受控 preedit 测试单独保留。

示例已通过 check 与 release 构建。实际 UI 检查确认中文显示、固定表头、升降序排序、原生金额编辑框、红色校验说明及保存后的真实值。UI 自动化工具的横向注入未改变窗口，以原生滚轮回归记录该输入路径的结果，不把工具调用本身当成通过。上述结果不代表一亿行查询／排序性能；离屏 AX 列动作仍未计为完成。
